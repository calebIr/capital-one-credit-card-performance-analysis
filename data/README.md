# Data Documentation

## Source
Capital One Financial Corporation — Q3 2026 Earnings Release and Financial Supplement.

## Scope
Credit Card business financial performance and credit risk metrics, covering Q3 2025 through Q3 2026.

## Data Preparation
- Extract quarterly financial metrics from the published financial supplement.
- Clean and reshape extracted tables using Excel Power Query.
- Validate reported figures against the original source.
- Prepare structured data for financial analysis, Python, SQL, and Power BI.

## Important Notes
- Monetary values are reported in USD millions unless otherwise indicated.
- Percentage rates, decimal fractions, and monetary values must be distinguished.
- Source financial statements and cleaned datasets should remain clearly identified.
- This is an independent educational portfolio project, not an official Capital One analysis.
